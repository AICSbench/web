# AICSbench web

The public results site for [AICSbench](https://github.com/AICSbench/aicsbench),
the open benchmark for AI coding agents across languages and frameworks.

- A static SvelteKit site, deployed to GitHub Pages.
- It only reads the JSON exported from
  [AICSbench/data](https://github.com/AICSbench/data); all calculations
  happen in `aicsbench`.

This repository is being set up in Phase 5. See
[docs/phase-5](https://github.com/AICSbench/aicsbench/tree/main/docs/phase-5)
in the main repository for the plan.
